Haz clic en una imagen para redimensionarla, elegir si afecta al texto o moverla libremente

Aún no hay texto cargado. Pulsa “Cargar texto” para pegar el modelo de contrato base (puede incluir imágenes, como un membrete o un logo). Luego coloca el cursor en cualquier punto: con “+ Campo” abres una ventana para escribir la información que debe ir ahí (nombre del cliente, fecha, monto...); con “+ Imagen” insertas una foto, firma o sello. También puedes pegar (Ctrl/Cmd+V) o arrastrar una imagen directamente sobre el documento y se detectará e incrustará automáticamente. Haz clic sobre cualquier imagen para arrastrar su esquina y cambiar el tamaño, elegir si el texto la rodea o no, y moverla a cualquier parte de la hoja.

Guardar como modelo

Se guarda el documento tal cual está ahora (texto, campos e imágenes) en este navegador. Luego podrás seleccionarlo, completar los campos para un caso puntual y exportarlo a Word: el modelo quedará intacto para usarlo de nuevo.
